## 现场创建 .venv · 给项目一个独立的包环境

确认远端目录没有 .venv，运行 python3 -m venv .venv。展开这个目录，点开 pyvenv.cfg，指一下 bin/python，再用 .venv/bin/python -m pip install -r requirements.txt 安装。安装后展开对应 Python 版本目录下的 site-packages，找 flask 和 werkzeug。requirements.txt 是声明，.venv 是实际环境。两个项目需要不同版本的 Flask 时各用各的环境；换机器按清单重新创建。我们直接调用 .venv/bin/python，省略激活步骤。

## 代码刚导入就报错，先查什么？

## 快捷键速查 · 日常编辑

Ctrl+D 是把下一处相同文字加入选区，先选中一个词，再每按一次多选一处。Alt+单击适合手动挑位置。三个行操作只需要把光标放在行里。演示保存时在 README 加一行，Ctrl+S 看白点消失，Ctrl+Z 撤销，Ctrl+Y 重做，最后 Ctrl+Z、Ctrl+S 清掉演示文字。到游戏源码时用编辑练习底稿把这些操作做一遍。
